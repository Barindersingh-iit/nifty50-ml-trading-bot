# Nifty 50 ML Trading Bot

## Project Structure

### 1. **data/**
   - This folder contains raw and processed data for training and testing ML models. 
   - Subfolders: `raw/`, `processed/`

### 2. **ml_models/**
   - Folder for storing ML model scripts. Each model should have its own script.

### 3. **trading_engine/**
   - Core logic for executing trades.
   - Scripts for live trading and simulation.

### 4. **backtesting/**
   - Folder for backtesting scripts to evaluate the performance of models.

### 5. **inference/**
   - Scripts that handle making predictions using trained models.

### 6. **notebooks/**
   - Jupyter notebooks for exploratory data analysis, model training, and evaluation.

### 7. **configs/**
   - Configuration files for model parameters, trading strategies, etc.

### 8. **requirements.txt**
   - Python packages required for the project.

### 9. **README.md**
   - Documentation about the project, its setup, and usage.

### 10. **LICENSE**
   - The licensing terms for the project.
